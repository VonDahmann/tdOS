Performance Criteria

  • Arrival Time: The exact time when a process enters the Ready Queue.
  • Burst Time: The total CPU time a process requires to finish execution.
  • Turnaround Time (ATT): Total time a process spends in the system from arrival to termination.
    Turnaround Time = Completion Time - Arrival Time
  • Waiting Time (AWT): The total time a process spends waiting in the Ready queue.
    Waiting Time = Turnaround Time - Burst Time
  • Response Time (ART): Time from when a process arrives until it gets the CPU for the first time.
    Response Time = First CPU Start - Arrival Time
